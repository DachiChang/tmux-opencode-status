# Triage Labels

When a skill refers to a triage role, use the corresponding GitHub label below.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting maintainer review |
| needs-info | needs-info | Awaiting more information from the reporter |
| ready-for-agent | ready-for-agent | Fully specified and ready for an unattended agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be addressed |

To use different label names, edit the GitHub label column.
